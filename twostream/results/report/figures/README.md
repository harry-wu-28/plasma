# Figures

Figures used by the reports. The `ee_*.png` files are copies of the talk figures in
`../../talk/figures/` (same names without the prefix); re-copy them if the talk figures change.
Prefix `ee_` = electron-electron report, `ei_` = electron-ion (Buneman) report. The e-i report
shows a labelled placeholder box for any file that is missing.

| File | Report | Content |
|---|---|---|
| `ee_dispersion_stable_unstable.png` | electron-electron | Chen's graphical method: stable vs unstable |
| `ee_phase_space.png` | electron-electron | phase space at start / growth / trapping (random start) |
| `ee_growth_fastest_mode.png` | electron-electron | fastest mode amplitude vs unfitted theory slope (quiet start) |
| `ee_spacetime_Ex.png` | electron-electron | E_x vs position and time (quiet start) |
| `ee_growth_rate_vs_k.png` | electron-electron | measured γ(k) vs Chen's curve (quiet start) |
| `ei_growth_mode.pdf` | electron-ion | `ln|E_k(t)|` for mode m = 16, with the linear-phase fit |
| `ei_dispersion.pdf` | electron-ion | measured γ/ω_pe and Re ω/ω_pe per box mode vs. k v0/ω_pe, against the exact quartic roots |
