# Figures

Drop finished figures here using the filenames below. `main.tex` shows a labelled
placeholder box for any file that is missing, so the paper compiles either way.

| File | Content |
|---|---|
| `growth_mode.pdf` | `ln|E_k(t)|` for the fastest-growing mode, with the linear-phase fit |
| `gamma_vs_k.pdf` | measured γ(k)/ω_b vs. k v0/ω_b, against the cold-beam dispersion relation |
| `convergence.pdf` | γ_max error and late-time energy drift vs. particles per cell, Δx, and shape order |

Generate figures as vector PDF (matplotlib `savefig("x.pdf")`), sized for a 3.4 in column.
